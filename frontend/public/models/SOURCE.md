# Adult horse model

`horse-adult.glb` is the animated morph-target horse distributed with the
Three.js r185 examples:

https://github.com/mrdoob/three.js/blob/r185/examples/models/gltf/Horse.glb

It is stored locally so the `/animation` experience does not depend on a
third-party runtime request. Keep the source attribution and review the
upstream Three.js license when replacing or redistributing the model.
